
## Publish with GitHub Pages

1. Create a **public** GitHub repository named `minto-maritime-profile`.
2. Upload:
   - `index.html`
   - `styles.css`
   - `README.md`
3. Commit the files to the `main` branch.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select:
   - Branch: `main`
   - Folder: `/ (root)`
7. Save.

Your website will normally be available at:

```text
https://YOUR-GITHUB-USERNAME.github.io/minto-maritime-profile/
```

## Privacy choice

The public site intentionally does **not** publish:

- date of birth
- nationality
- home/street address
- seafarer document numbers
- certificate numbers
- scanned certificate PDFs

Those can be supplied directly to employers when requested.
