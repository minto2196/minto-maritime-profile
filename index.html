06 / PERSONAL TECHNICAL PROJECT

Learning from scratch: an IoT remote-controlled model ship

BUILT DURING THE COVID PERIOD

A self-directed technical challenge

During my B.Sc. Nautical Science studies and the COVID period, I used the time to independently design and build a miniature remotely controlled ship.

I wanted to understand how mechanical systems, electronics, programming and wireless control could work together in one vessel-inspired system.

Much of this was new to me. I learned the required electronics, microcontroller logic, HTML/CSS interface development and Wi-Fi communication through documentation, online technical resources, experimentation and repeated troubleshooting.

This was before modern generative-AI assistants such as ChatGPT were available to me. I therefore had to work through the problems myself, understand why something failed and keep experimenting until the system worked.

The project was not simply about making a model move. It became an exercise in independent learning, systems integration, persistence and troubleshooting.

SYSTEM

What I built

Controller Arduino Mega 2560

Managed mechanical functions including propulsion, steering and pump operation.

Connectivity NodeMCU ESP8266

Provided local Wi-Fi connectivity between the ship and control interface.

Interface HTML / CSS

Developed a locally hosted control interface accessible from another device on the network.

Simulation Shipboard functions

Propulsion, steering, navigation-light logic and pumps representing loading/discharging functions.
